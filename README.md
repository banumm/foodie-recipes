# Foodie 🍴

Мобильное приложение с рецептами на React Native (Expo). Все экраны, данные и состояние хранятся в файлах проекта — приложение можно открыть в Expo Snack без установки зависимостей локально.

## Файлы в корне

| Файл | Назначение |
| --- | --- |
| `App.js` | Навигация: нижние вкладки + стек экранов |
| `screens.js` | Экраны: главная, избранное, «Моя еда», детали, форма |
| `store.js` | Глобальное состояние (избранное и свои рецепты) через Context + useReducer |
| `data.js` | 12 категорий и 11 демонстрационных рецептов |
| `package.json` | Зависимости Expo |
| `app.json` | Конфигурация Expo |

## Запуск в Expo Snack

1. Откройте [snack.expo.dev](https://snack.expo.dev).
2. Нажмите **Import Git Repository** и вставьте ссылку:
   `https://github.com/banumm/foodie-recipes`
3. Если Snack предложит обновить зависимости — согласитесь (**Update dependencies**).
4. Запустите превью в браузере или отсканируйте QR-код в **Expo Go**.

## Проверка требований

| № | Требование | Где реализовано |
| --- | --- | --- |
| 1 | Импорт в Snack | `package.json` и `app.json` в корне репозитория |
| 2 | Не менее 10 категорий по горизонтали | 12 категорий в горизонтальном `FlatList` (`HomeScreen`) |
| 3 | Детали рецепта | `DetailScreen`: ингредиенты, инструкции, время, порции, калории, сложность |
| 4 | Фильтр по категории | Нажатие на категорию фильтрует список |
| 5 | Сердечко | 🤍 / ❤️ переключаются повторным нажатием |
| 6 | Избранное | Вкладка «Избранное» |
| 7 | «Моя еда» и «Добавить новый рецепт» | Вкладка «Моя еда» с кнопкой «＋ Добавить новый рецепт» |
| 8 | Форма | Название, загрузка изображения (`expo-image-picker`), ингредиенты, инструкции, «Сохранить рецепт» |
| 9 | «Мои рецепты» | Сохранённый рецепт появляется в списке «Мои рецепты» |
| 10 | Полная информация | По нажатию открывается экран деталей с названием, изображением, ингредиентами и инструкциями |
| 11 | «Редактировать» и «Удалить» | Кнопки на экране своего рецепта; редактирование открывает ту же форму, удаление — с подтверждением |
| 12 | Кнопка «Назад» | «← Назад» на экранах деталей и формы |
