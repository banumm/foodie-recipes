# Foodie 🍴

Мобильное приложение с рецептами на React Native (Expo). Все экраны, данные и состояние хранятся в файлах проекта — приложение можно открыть в Expo Snack без установки зависимостей локально.

## Файлы в корне

| Файл | Назначение |
| --- | --- |
| `App.js` | Навигация: нижние вкладки + стек экранов |
| `screens.js` | Экраны: главная, избранное, «Моя еда», детали, форма |
| `store.js` | Глобальное состояние (избранное и свои рецепты) через Context + useReducer |
| `data.js` | 13 категорий и 11 демонстрационных рецептов |
| `package.json` | Зависимости Expo |
| `app.json` | Конфигурация Expo |

## Запуск в Expo Snack

1. Откройте [snack.expo.dev](https://snack.expo.dev).
2. В панели файлов нажмите **⋮ → Import git repository** и вставьте ссылку:
   `https://github.com/banumm/foodie-recipes`
3. Snack автоматически выберет **Expo SDK 51** — эта конфигурация уже проверена, менять SDK не нужно.
4. Запустите превью в браузере или отсканируйте QR-код в **Expo Go** (для SDK 51 нужна совместимая версия Expo Go).

> В веб-превью подтверждение удаления реализовано через `window.confirm`, потому что `Alert.alert` в `react-native-web` не показывает диалог. На телефоне используется штатный `Alert.alert`.

## Проверка требований

| № | Требование | Где реализовано |
| --- | --- | --- |
| 1 | Импорт в Snack | `package.json` и `app.json` в корне репозитория |
| 2 | Не менее 10 категорий по горизонтали | 13 категорий (12 рецептных + «Все») выводятся компактными чипами — все видны сразу на главной, без прокрутки |
| 3 | Детали рецепта — все шесть характеристик | `DetailScreen`: категория, время приготовления, количество порций, калории, уровень сложности, ингредиенты — всё видно без прокрутки |
| 4 | Фильтр по категории | Нажатие на категорию фильтрует список |
| 5 | Сердечко | 🤍 / ❤️ переключаются повторным нажатием |
| 6 | Избранное | Вкладка «Избранное» |
| 7 | «Моя еда» и «Добавить новый рецепт» | Вкладка «Моя еда» с кнопкой «＋ Добавить новый рецепт» |
| 8 | Форма | Название, загрузка изображения (`expo-image-picker`), ингредиенты, инструкции и «Сохранить рецепт» — всё видно сразу; ниже дополнительные характеристики (категория, время, порции, калории, сложность) |
| 9 | «Мои рецепты» | Сохранённый рецепт появляется в списке «Мои рецепты» |
| 10 | Полная информация | У своего рецепта на экране деталей видны все характеристики, изображение, ингредиенты и инструкции |
| 11 | «Редактировать» и «Удалить» | Кнопки сразу под характеристиками своего рецепта (видны без прокрутки); редактирование открывает ту же форму, удаление — с подтверждением |
| 12 | Кнопка «Назад» | «← Назад» на всех экранах: главная, избранное, «Моя еда», детали, форма |
